## Completion rule

A case moves from `pending` to `ready` only when it has:

1. a real Gemini Notebook output captured from the documented source + exported prompt;
2. a redistribution-safe image asset;
3. Prompt ID and generation date recorded;
4. the required non-guaranteed-output disclaimer;
5. no private or unrelated identifiable information.

See [`SUBMISSION.md`](SUBMISSION.md).

## Why this status board is public

A partially completed but honest showcase is more useful than filling empty slots with mock screenshots and presenting them as real output. CSS-based visual previews remain available in the live app while these real examples are collected.
