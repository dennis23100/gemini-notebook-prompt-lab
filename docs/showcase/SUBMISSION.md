# Showcase Example Submission Checklist

Use this checklist when adding a real generated showcase example.

## Required metadata

- [ ] Theme: Flexible Comic / Technology / Ink Wash
- [ ] Audience: Children / Youth / Adults
- [ ] Prompt ID recorded from the current prompt pack
- [ ] Demo source: `docs/showcase/source.md`
- [ ] Generation date recorded
- [ ] Gemini Notebook product name/version context noted when useful
- [ ] No private source material was used
- [ ] Contributor has the right to redistribute the submitted image

## Output integrity

- [ ] The example was produced from the documented source + prompt workflow
- [ ] No source facts were manually changed between audience variants
- [ ] Any crop/resizing is disclosed
- [ ] No manual redesign is presented as model-generated output
- [ ] The example is labeled as non-guaranteed output

## Privacy and safety

- [ ] No identifiable learner/student data
- [ ] No private names, emails, account information, or confidential screenshots
- [ ] No unrelated identifiable people in the image unless publication permission exists

## Suggested metadata block

```yaml
case_id: flexible-comic-children
prompt_id: <actual prompt id>
theme: Flexible Comic
audience: Children
source: docs/showcase/source.md
generated_at: YYYY-MM-DD
editing: crop-only | none
notes: <optional>
```

## Required public disclaimer

> Example output produced from the documented source + prompt workflow. Gemini Notebook output can vary by source, product version, settings, and generation run.
