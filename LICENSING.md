# Licensing in Toolkit 60

Toolkit 60 is a monorepo. Different kinds of material can use different licenses, so contributors should check the affected subproject before copying, redistributing, or adapting content.

## Code

Unless a subproject explicitly states otherwise, project-authored software code is released under the root [MIT License](LICENSE).

The Gemini Notebook Prompt Lab code is also covered by its local [`notebooklm/LICENSE`](notebooklm/LICENSE).

## Prompt data and metadata

The Gemini Notebook Prompt Lab's project-authored prompt transformations and metadata are licensed separately under **CC BY 4.0**. See [`notebooklm/LICENSE-DATA.md`](notebooklm/LICENSE-DATA.md).

This distinction exists because reusable prompt/data content is not the same artifact as application source code.

## Third-party material

External inspirations, upstream repositories, trademarks, and other third-party material are not relicensed merely because they are referenced by Toolkit 60. Follow the original license and attribution requirements.

For NotebookLM-specific provenance and upstream notices, see [`notebooklm/THIRD_PARTY_NOTICES.md`](notebooklm/THIRD_PARTY_NOTICES.md).

If a future subproject needs a different license, it should include a local license file and document the difference clearly in its README.
