## 🚧 Project status

This project is currently in the planning stage. The folder is reserved inside **Toolkit 60** so the video-editing tools can grow as an independent project without mixing their code with the Gemini Notebook project.

## Planned directions

Potential modules include:

- smart silence / dead-air detection
- subtitle and caption workflows
- batch media processing
- scene and shot utilities
- short-form video helpers
- reusable export presets
- editing workflow automation
- local-first creator utilities

The exact scope will be narrowed as the first working prototype is built.

## Design principles

The project should aim to be:

- practical rather than demo-only
- easy to run locally
- transparent about what processing happens
- friendly to batch workflows
- modular enough to use only the features you need
- documented well enough for other creators to fork and improve

## Planned structure

```text
video-editing/
├── README.md
├── README.zh-TW.md
├── app/
├── scripts/
├── docs/
├── tests/
└── examples/
```

This structure may change once the first tool is selected.

## Have an idea?

Feature suggestions and real editing pain points are welcome. The most useful first release should solve a concrete repetitive editing problem rather than trying to replace a full video editor.
