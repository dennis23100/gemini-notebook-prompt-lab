# Code of Conduct

We want this project to be useful to educators, developers, community teachers, researchers, and learners from different backgrounds.

Be respectful, specific, and constructive. Critique ideas and implementation choices rather than people. Do not harass, threaten, discriminate, publish private information, or intentionally derail project spaces.

Maintainers may edit or remove contributions and interactions that violate these expectations and may restrict participation when necessary to keep the project safe and productive.

For sensitive conduct reports, use the private contact method listed in the maintainer's GitHub profile rather than opening a public issue.
