# Gemini Notebook Prompt Lab v1.0.0

First stable public release of the NotebookLM / Gemini Notebook subproject inside **Toolkit 60**.

## Highlights

- 90 age-adaptive prompts across 30 visual themes and 3 audience profiles.
- Traditional Chinese and English interface; built-in prompt bodies remain English for direct use with Gemini Notebook.
- Prompt Library with search, age/category filters, favorites, import/export, sharing, and age-variant comparison.
- Lightweight illustrative style previews for the visual-theme cards.
- Prompt Lab covering 10 source-grounded Gemini Notebook workflows.
- Prompt Chain Builder for repeatable extract → create → verify workflows.
- Deterministic local Prompt Quality Check / linter.
- Light-first UI with optional dark mode.
- Privacy-first, local-only architecture with no account, backend, analytics, or API key required.
- PWA/offline support.
- Automated validation and GitHub Pages deployment.
