# Gemini Notebook Prompt Lab v1.1.0

This release focuses the repository around one clear product and improves the first-use / feedback experience.

## Highlights

- Repository positioning is now focused on **Gemini Notebook / NotebookLM Prompt Lab** rather than unrelated future tools.
- GitHub Pages root now opens the Prompt Lab directly; the previous `/notebooklm/` path remains available for compatibility.
- Added **Simple mode** for first-time users: Prompt Library + Prompt Lab are primary, while Chain Builder and Quality Check can be revealed as advanced tools.
- Added a visible **Feedback** entry that routes real users to GitHub issue forms.
- Added lightweight illustrative style previews for theme cards and clarified that they are visual-direction examples, not guaranteed output.
- Simplified age/category filtering by removing redundant “All” pills.
- Refined the light-first visual design with softer ambient depth and optional dark mode.
- Added repository-level project story, showcase strategy, maintainer/support docs, CODEOWNERS, and a user-feedback issue form.
- Added a **3 themes × 3 audiences = 9 real generated examples** showcase milestone instead of bloating the repository with 90 screenshots.
- Documented the project’s real-world teaching origin, including an in-person teaching session with 100+ attendees, without conflating that with GitHub usage.
- Continued automated validation, tests, PWA/offline support, and GitHub Pages deployment.

## Current scope

- 90 age-adaptive prompts
- 30 visual themes
- 3 audience profiles
- 10 Gemini Notebook workflows
- Traditional Chinese + English UI
- local-first / privacy-first architecture
- Prompt Library, Prompt Lab, optional advanced Chain Builder and Quality Check
