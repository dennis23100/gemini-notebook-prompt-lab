# Real-output preview assets

These JPEG files are optimized website previews made from representative Gemini Notebook outputs supplied for the project.

## Mapping

Each sprite contains three 16:9 slides in this order:

1. Children / 兒童 (≤15)
2. Youth / 青年 (16–34)
3. Mature readers / 成熟讀者 (35+)

Files:

- `comic-sprite.jpg` — Flexible Comic / 漫畫（不拘）
- `stars-sprite.jpg` — Stars / 星星
- `fairy-animation-sprite.jpg` — Fairy-tale Animation / 童話動畫電影

The original supplied slides are 1376 × 768. Each sprite keeps the same 16:9 geometry for every tile, and the prompt-card CSS preserves that ratio instead of stretching the artwork.

The README displays these same representative outputs directly from this folder, so the public repository and the live Prompt Library are showing the same selected examples.

These are representative examples, not deterministic promises: another generation run may produce a different visual treatment while following the same prompt direction.
