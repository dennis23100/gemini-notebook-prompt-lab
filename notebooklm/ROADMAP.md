# Roadmap

The roadmap prioritizes **usefulness and contribution surface area** over raw prompt count.

## v1.1 — Community-ready

- [ ] Add screenshots/GIF demo to README after the public Pages URL is live.
- [ ] Add URL-addressable filters (`?age=youth&category=...`).
- [ ] Add prompt diff view to compare revisions and age variants.
- [ ] Add accessibility smoke tests.
- [ ] Add community prompt-pack validation.

## v1.2 — Better prompt engineering

- [ ] Version individual prompts with change notes.
- [ ] Add optional rubric profiles for teaching, research, presentation, and study use.
- [ ] Add a local “grounding coverage” explainer that highlights which instruction clauses triggered each linter rule.
- [ ] Add export formats for Markdown and CSV in addition to JSON.

## v1.3 — Integrations

- [ ] Prototype an optional browser extension that can place selected prompts into the active Gemini Notebook panel.
- [ ] Keep the website fully usable without the extension.
- [ ] Explore a documented, permission-minimal integration path before publishing an extension.

## Later

- [ ] More languages.
- [ ] Optional sync that is off by default.
- [ ] Community showcase page for teaching workflows.
- [ ] Reproducible prompt-evaluation fixtures for source-grounding behavior.

## Non-goals

- Scraping private Gemini Notebook content.
- Auto-submitting prompts without user review.
- Claiming a deterministic linter score is an objective measure of model output quality.
- Collecting user prompt content for analytics.
