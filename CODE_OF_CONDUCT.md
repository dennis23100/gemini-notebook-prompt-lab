# Code of Conduct

Toolkit 60 is intended to be useful to creators, educators, developers, researchers, and contributors from different backgrounds.

Please be respectful, specific, and constructive. Critique ideas, documentation, code, data, and implementation choices rather than people.

Unacceptable behavior includes harassment, threats, discrimination, deliberate intimidation, publishing private information, spam, or intentionally derailing project spaces.

Maintainers may edit or remove contributions and interactions that violate these expectations and may restrict participation when necessary to keep the project safe and productive.

For sensitive conduct reports, use the private contact method available through the primary maintainer's GitHub profile rather than opening a public issue.
